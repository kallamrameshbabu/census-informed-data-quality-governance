# SHA-256 checksums of the input data files

Every number reported in the manuscript is traceable to one of the files
below. The digests were produced by the ingestion notebook at run time and
are recorded in `outputs/tables/T0_dataset_provenance.csv`, which is the
authoritative provenance record; this file is a convenience copy.

Verify with:

    sha256sum <file>                              # Linux / macOS / Colab
    Get-FileHash <file> -Algorithm SHA256         # Windows PowerShell

## Not included in this repository (CC BY 4.0, excluded for file size)

826ff6b98210100762f194944aa43a342bfda2371408a3dc41f2e8ed37c010d3  online_retail_II.csv

  online_retail_II.csv  109,192,007 bytes  — UCI Online Retail II, 1,067,371 rows

Online Retail II carries the same CC BY 4.0 licence as the other two corpora.
It is omitted only because 109 MB exceeds GitHub's practical file limits.
Download it from https://archive.ics.uci.edu/dataset/502 and place it at
`data/raw/online_retail_II.csv`.

UCI distributes this dataset as an .xlsx workbook with two sheets
(2009-2010 and 2010-2011). Notebook 01 converts it: place the .xlsx at
`data/raw/online_retail_II.xlsx` and the conversion cell merges both sheets
into the single CSV whose digest is listed above. If your digest differs
after conversion, check that both sheets were merged and that the
`_source_sheet` column is present.


## A caveat worth reading

A digest mismatch does not always mean the data differs. Bank Marketing is
distributed semicolon-delimited with quoted fields; opening and re-saving it
in a spreadsheet application will change the delimiter, the line endings, or
both, and produce a different digest for identical data. Check the delimiter
before concluding the file is wrong.
