## Important note on these three checksums

These digests were computed against the copies of `bank.csv`, `bankfull.csv`,
and `diabetic_data.csv` used during development of this artifact. Before
relying on them:

1. Confirm they match the files actually committed to this repository —
   run `sha256sum data/raw/*.csv` yourself and compare.
2. Bank Marketing is distributed with a semicolon delimiter and quoted
   fields; a file that has been re-saved with a comma delimiter by
   spreadsheet software will produce a different digest even though the
   data is unchanged. If your checksum does not match, check the delimiter
   before assuming the data differs.
3. The `T0_dataset_provenance.csv` table in `outputs/tables/` is generated
   directly by the notebooks at run time and is the authoritative source
   for exactly which file produced the manuscript's numbers. This file is
   a convenience reference, not a substitute for that table.
